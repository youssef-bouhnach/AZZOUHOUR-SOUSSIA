## 💡 Conseils

### Pour développer
1. Garde les 2 terminaux ouverts (backend + frontend)
2. Les changements frontend sont automatiques (hot reload)
3. Les changements backend nécessitent un refresh du navigateur
4. Consulte les logs Laravel si erreur: `tail -f backend/storage/logs/laravel.log`

### Pour tester
1. Utilise les comptes de test fournis
2. Teste d'abord en tant qu'utilisateur normal
3. Puis teste en tant qu'admin
4. Réinitialise la DB si besoin

### Pour débugger
1. Console du navigateur (F12) pour le frontend
2. Logs Laravel pour le backend
3. Network tab pour voir les requêtes API
4. `php artisan tinker` pour interroger la DB
